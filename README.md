# Simple API Java

Aplicação API 
Projeto de fork par aula de DevOps da Fiap, edicao arquivos e painel Azure
## Pré-requisitos

- Java 21
- Git
- Docker


## Build e execução

```sh
docker compose up --build
```

## Testes unitários (validação)

./mvnw test


## Documentação online (OpenAPI)
